# Contributing to @oibus/pi

## AVEVA software

Working on the helper requires PI AF Client and the AF SDK on your machine. They come with
[AVEVA's own terms](https://www.aveva.com/en/legal/), which you need to have accepted yourself: this
repository grants no right to them. This is information, not legal advice.

Never commit an AVEVA file (`OSIsoft.*`, `Aveva.*`, `PIInterop*` or any other) to this repository,
and never let one reach the build output or the npm package.

## Contributions

Contributions are accepted under the Apache License 2.0. Sign off each commit
(`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org/).
